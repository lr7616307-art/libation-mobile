# Compatibility

- Minimum Android API configured: 29 (Android 10).
- Target framework: .NET 10 / Android API 36.
- Android runtime identifiers: android-arm (ARMv7) and android-arm64.
- ARMv7 support is required for the initial target device.
- Android 10 support is best-effort and must be validated on a physical device.
- No APK has yet been verified on-device.
