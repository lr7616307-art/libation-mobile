# Libation Mobile

An Android-focused community project exploring a mobile interface for compatible Libation functionality. This is an independent, unofficial project and is not affiliated with Audible or the upstream Libation maintainers.

## Status

Starter scaffold and architecture work in progress. No APK is currently verified as buildable or installable.
